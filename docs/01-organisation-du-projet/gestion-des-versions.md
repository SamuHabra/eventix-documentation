# Gestion des versions

* **Git** est utilisé pour le versionnement.
* `main` contient la version validée.
* Chaque modification importante est effectuée sur une branche dédiée.
* Les modifications sont intégrées via Pull Request.
* Les décisions importantes sont conservées dans `registres/decisions.md`.
* Les changements majeurs sont enregistrés dans `registres/changements.md`.
* Aucun fichier `final-v2-definitif.md` : l'historique Git fait foi.

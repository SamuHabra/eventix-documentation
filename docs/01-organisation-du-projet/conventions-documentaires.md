# Conventions documentaires

* Format officiel : **Markdown (`.md`)**.
* Documentation rédigée en **français**.
* Un fichier = un objectif précis.
* Titres et sous-titres structurés avec Markdown.
* Utiliser des tableaux pour les informations structurées.
* Utiliser Mermaid pour les diagrammes lorsque pertinent.
* Toute décision importante doit être traçable.
* Éviter les informations contradictoires ou non vérifiées.
* GitHub constitue la source de vérité de la documentation validée.

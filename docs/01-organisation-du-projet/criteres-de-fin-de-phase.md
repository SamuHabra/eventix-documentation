# Critères de fin de phase

La Phase 1 est terminée lorsque :

* Les documents de la phase sont rédigés.
* L'équipe les a relus.
* Les décisions importantes sont documentées.
* Les questions critiques sont résolues ou reportées.
* Les documents sont cohérents entre eux.
* L'équipe valide officiellement la phase.
* Le statut passe à **VALIDÉE**.

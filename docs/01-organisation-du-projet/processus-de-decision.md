# Processus de décision

1. Identifier le problème.
2. Analyser le contexte et les contraintes.
3. Proposer les options possibles.
4. Comparer les options.
5. Discuter en équipe.
6. Voter si une décision est nécessaire.
7. Appliquer la majorité simple.
8. Documenter la décision dans `registres/decisions.md`.
9. Informer l'équipe des conséquences.

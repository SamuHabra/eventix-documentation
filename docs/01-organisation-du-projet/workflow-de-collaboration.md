# Workflow de collaboration

1. Créer une branche à partir de `main`.
2. Travailler sur la tâche attribuée.
3. Faire des commits clairs et réguliers.
4. Pousser la branche sur GitHub.
5. Créer une Pull Request vers `main`.
6. Faire relire par un autre membre.
7. Corriger si nécessaire.
8. Merger après validation.
9. Synchroniser les branches avec `main`.
